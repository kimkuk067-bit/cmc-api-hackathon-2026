# CMC API Hackathon 2026

Project workspace for [Build with CMC: API Hackathon, Round 2](https://coinmarketcap.com/api/resources/api-hackathon-2026-11/). The two concepts are in prototype evaluation.

## Prototype concepts

| Concept | What it explores | Proposed track |
| --- | --- | --- |
| Market Cap Rank Explorer | Compare weekly market-cap rankings with the rank calculated using the previous week's circulating supply. | Data and Visualisation |
| Crypto Claim Verifier | Compare reported token-supply claims with CMC historical data, official sources, and public on-chain records. | AI Agents and Automation |

## CMC API configuration

Use `CMC_API_KEY` in your local environment. `.env.example` lists the required variable. Store its value in a local `.env` file or a deployment secret.
